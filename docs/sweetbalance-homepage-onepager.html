Main Feature

주인공 — 샐러드 습관 캘린더

“메뉴 고민 해결”과 “습관 기록”을 따로 두지 않고 하나의 흐름으로 붙인 것이 핵심입니다.

고민 시작버튼 또는 날짜 클릭
메뉴 결정목록 · 테스트 · 무작위
그대로 기록해당 날짜에 도장
연속 일수 갱신스탯 · 진행바 · 응원
메뉴를 고르는 세 가지 방법. 달력 날짜를 누르면 7종 목록이 기본으로 열려 한 번에 기록됩니다. 무엇을 먹을지 모르겠으면 6문항 성향 테스트, 아무래도 상관없으면 무작위 추천으로 넘어갈 수 있습니다. 원하는 메뉴가 나올 때까지 다시 뽑을 필요가 없습니다.
테스트 설계. 선택지 하나가 성향 축 하나(단백질 · 속편함 · 든든함 · 따뜻함 · 빠름)에 3점을 줍니다. 축마다 등장 문항 수가 달라 최대 점수가 다르므로(12점 대 9점) 축별 최대점으로 정규화한 뒤 메뉴 가중치와 곱합니다. 729가지 전체 경로를 시뮬레이션한 결과 7종이 모두 9.7~17.4%로 출현하고, 시그니처 3종 합계는 46.8%입니다.

Interview

인터뷰 답변이 들어간 자리

질문나의 답변페이지 반영
① 손님바쁜 직장인 · 다이어터 “하루는 바쁘고, 메뉴 고민은 깁니다” 카피 / 모든 메뉴에 소요 시간 · 칼로리 · 단백질 동시 표기
② 첫 문장이 정도면 나도 꾸준히 할 수 있겠다 첫 화면 헤드라인에 그대로 사용
③ 대표 제품시그니처 샐러드 시그니처 3종으로 확장해 별도 섹션 + 메뉴 목록 상단 고정
④ 아이디어 기능습관 캘린더 + 고민 버튼 결합 페이지의 주인공 섹션. 고르기와 기록을 한 흐름으로 구현
⑤ 분위기신선한 초록 Vital Green 을 습관 섹션 전면 배경으로. 매뉴얼 팔레트 안에서만 반영

Design System

브랜드 매뉴얼 준수

#00614EVital Green
#007C5EHarmony Green
#FDFFE6Sunshine White
#84BA45Seed Green
#F6F4E8Paper
로고 공식 한글 수평형을 그대로 사용하고 Clear Space 를 로고 높이의 50% 이상 확보했습니다. 직접 만든 워드마크는 “지정 외 폰트로 로고 재현” 금지에 걸려 전부 걷어냈습니다. 마스코트 냠은 UI 아이콘이 아닌 일러스트 앵커로만 씁니다.
타이포 Montserrat(영문 · UI) + Pretendard(한글 본문 · UI), Chewy 는 디스플레이 전용이라 슬로건에만. 배경 마케팅 서피스는 Sunshine White, 순백은 카드 표면에만. Secondary 는 한 화면에 하나만 쓰는 규칙에 따라 Seed Green 으로 통일했습니다.
모션 Motion Don’ts 에 따라 지속 루프 애니메이션과 텍스트 튀기기를 넣지 않았고, 모든 지속시간을 500ms 이하로 맞췄습니다. 버튼은 매뉴얼 스펙대로 hover translateY(-2px) 180ms, press scale(0.98) 120ms 입니다. 아이콘 이모지와 ★ ✓ 기호를 UI에서 제거하고 stroke 1.75 인라인 SVG 27종으로 교체했습니다.
한 가지 예외. 샐러드 제품 일러스트에 한해 “Secondary 1색” 규칙의 예외를 승인받아 실제 식재료 색(토마토 · 옥수수 · 당근 · 곡물 · 크림)을 사용했습니다. UI 전반은 그대로 매뉴얼을 따릅니다.
