# 스윗밸런스 자사몰 홈페이지

샐러드·건강 간편식 브랜드 **스윗밸런스**의 한 페이지 자사몰 데모입니다.
메뉴 고르기와 습관 쌓기를 하나로 이어붙인 **샐러드 습관 캘린더**가 이 페이지의 주인공입니다.

홈페이지 접속 링크: https://choronglim.github.io/my-homepage-choronglim/

## 구성

| 섹션 | 내용 |
| --- | --- |
| 첫 화면 | "이 정도면 나도 꾸준히 할 수 있겠다" |
| 시그니처 3종 | 기본 · 단백질 · 포만감을 하나씩 맡는 세 그릇 |
| **샐러드 습관 캘린더** | 메뉴를 고르면 그대로 달력에 기록 → 연속 일수 갱신 |
| 미니게임 | 이름만 보고 그린 뒤 실제 일러스트와 비교 |
| 브랜드 소개 | 새벽에 만들어 아침에 도착 · 숨기지 않는 숫자 · 부담 없는 지속 |

## 메뉴를 고르는 세 가지 방법

- **목록에서 직접** — 달력 날짜를 누르면 7종 목록이 열리고, 누르면 바로 기록됩니다
- **6문항 성향 테스트** — 무엇을 먹을지 모를 때
- **무작위 추천** — 아무래도 상관없을 때

## 참고

- `index.html` 한 파일로 동작합니다. 로고와 마스코트는 파일에 임베드되어 있고,
  외부 요청은 브랜드 매뉴얼이 지정한 폰트(Montserrat · Chewy · Pretendard)뿐입니다.
- 습관 기록은 서버로 전송되지 않고 사용자 브라우저(localStorage)에만 저장됩니다.
- 디자인은 사내 **SweetBalance Brand Design System Manual (v2025.07.25)** 을 따릅니다.
- 제작 배경과 화면 설명은 [원페이저 문서](docs/sweetbalance-homepage-onepager.html)를 참고하세요.
